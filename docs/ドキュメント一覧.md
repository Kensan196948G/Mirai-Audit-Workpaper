# ドキュメント一覧

## はじめに

本一覧は、監査業務・証跡管理プロジェクトの文書を、利用目的別に案内します。原典5ファイルを精査した時点では、業務・要件・構想の資料はありますが、稼働するアプリケーションの実装や試験結果は確認できません。そのため、新規文書では次の表示を使います。

| 表示 | 意味 |
|---|---|
| 実装済み | ワークスペースで現物または実行結果を確認できたもの |
| 計画 | 要件、構想、運用案として定義したもの。利用可能とは限らない |
| 未確定 | 社内規程、関係者合意、製品選定、詳細設計等が必要なもの |

## 文書を読む際の注意

- 「する」「備える」と記載された箇所でも、要件・設計・運用案であり、稼働確認済みとは限りません。
- 正式な分掌、承認者、保存年限、監査意見・重要度の区分は、社内規程と関係者合意により確定してください。
- AppSuite、desknet's NEO、OneDrive、DirectCloud、Entra ID、HENNGE ONE等は候補・優先方針として原典に記載されていますが、採用・契約・設定済みとは確認できません。
- システムは情報整理と証跡管理を支援します。監査判断、経営判断、処分、法的評価を代替しません。
