# ステークホルダー・RACI

## 1. 目的

業務ごとの実行責任と承認責任を混同しないための案である。正式な職務分掌・監査役会規程・決裁権限規程との照合が必要であり、現時点では未承認。

## 2. 記号

- **R**: 実行担当
- **A**: 最終説明・承認責任
- **C**: 事前相談
- **I**: 情報共有
- **—**: 原則として関与なし

## 3. RACI案

| 活動 | 監査役会 | 監査役 | 総務部 | 被監査部門 | 情報システム | 法務・コンプライアンス |
|---|---|---|---|---|---|---|
| 年度監査計画の承認 | A | R | C | I | I | C |
| 個別監査の設計 | I/C | A/R | C | I | I | C |
| 日程・依頼の調整 | I | A | R | C | — | — |
| 証憑の提出 | I | A | C | R | — | — |
| 監査手続・調書作成 | I | A/R | C | C | — | C |
| 調書レビュー | A/C | R | I | — | — | C |
| 指摘内容の確定 | A/C | R | I | C | — | C |
| 改善計画の作成 | I | A/C | C | R | — | C |
| 改善完了の確認 | I/C | A/R | I | C | — | C |
| アカウント・技術運用 | I | A/C | C | I | R | C |
| セキュリティ事故対応 | I | C | C | I | R | A/C |
| 保存期間満了時の廃棄 | A/C | R | R | I | C | C |

## 4. 利益相反と代理

監査担当者または承認者に利益相反がある場合、その人物を案件権限から外し、事前に定めた代理者へ付け替える。代理、理由、期間、承認者を監査ログへ残す。自分が作成した調書を自分だけで最終承認しない。

## 5. 確定が必要な事項

補助使用人の位置付け、常勤・非常勤監査役の権限差、総務部が閲覧できる調書範囲、システム管理者の特権利用手続、監査役不在時の代理、外部専門家のアクセス期間。
