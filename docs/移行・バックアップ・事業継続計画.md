# 移行・バックアップ・事業継続計画

## 1. 位置付け

既存の監査資料がどこに、どの形式・品質で保管されているかは未確認である。本書は移行、バックアップ、災害時継続の計画案であり、移行対象・件数・RPO/RTOは調査後に確定する。

## 2. 移行対象候補

| 対象 | 主な確認項目 | 移行方針案 |
|---|---|---|
| 年度監査計画 | 年度、承認、版、対象 | 稼働年度＋必要な過年度を構造化移行 |
| 監査調書 | 監査番号、作成者、レビュー、確定版 | 確定版と索引を優先。草稿は必要性を個別判断 |
| 受領証憑 | 出所、受領日、版、重複、個人情報 | 正本・出所を確認しハッシュ付与 |
| 指摘・是正 | 状態、責任者、期限、完了根拠 | 未完了・継続監視を優先して移行 |
| 利用者・組織 | 在籍、役割、異動、利益相反 | Entra ID等の正規マスターから同期 |

## 3. 移行手順案

```mermaid
flowchart LR
  A[資産棚卸し] --> B[対象・除外承認]
  B --> C[クレンジング・マッピング]
  C --> D[試行移行]
  D --> E[件数・ハッシュ・参照検証]
  E --> F[利用者受入]
  F --> G[本番移行]
  G --> H[旧環境凍結・廃棄判断]
```

移行前後で件数、容量、必須項目、版、ハッシュ、参照関係、アクセス権、サンプル目視を照合する。不一致は理由と承認を残し、原本を先に削除しない。

## 4. バックアップ方針案

| 対象 | 方式・頻度案 | 復元確認 |
|---|---|---|
| AppSuite台帳・設定 | 日次＋重要変更前のエクスポート | 四半期にレコード・履歴復元 |
| DirectCloud正本 | 製品冗長化に加え、契約範囲・世代・削除保護を確認 | 半期に指定版・フォルダ復元 |
| OneDrive作業領域 | 製品の版・ごみ箱だけに依存せず必要データを確定移管 | 四半期にファイル復元 |
| 監査ログ | 追記型・分離保管、日次転送 | 月次に欠落・検索性確認 |
| 構成・手順 | 変更時および月次 | 再構築演習 |

バックアップ成功表示だけでなく、実データを隔離環境へ復元し、読取・参照・権限を確認する。暗号鍵・復号手順・管理者連絡先も復旧可能にする。

## 5. 事業継続

| 事象 | 代替手段案 | 復帰条件 |
|---|---|---|
| ポータル・AppSuite停止 | 承認済みオフライン連絡網と連番付き緊急記録票 | 停止中記録を重複なく取り込み、責任者確認 |
| 文書保管停止 | 新規証憑を暗号化隔離領域へ一時保管 | マルウェア検査、ハッシュ、受領時刻を付し正本移管 |
| SSO停止 | 安全な緊急ID方式を事前承認。共有IDは禁止 | 緊急ID停止、操作ログレビュー |
| 拠点・ネットワーク停止 | 代替拠点・管理端末・連絡手段 | 接続・端末安全性確認 |
| SaaS長期停止・撤退 | 定期エクスポートから代替環境へ復元 | 完全性、権限、監査証跡を受入確認 |

## 6. 復旧優先順位案

1. 認証・権限と監査ログ。
2. 正本証憑・確定調書。
3. 実施中監査、未完了指摘、期限情報。
4. 通知・検索・補助機能。

## 7. 必須の事前決定

- 保存年限、移行対象年度、旧媒体の廃棄承認者。
- RPO・RTO、バックアップ世代・保管地域、復旧責任者。
- SaaS障害・契約終了時のデータ出力形式、費用、期限、削除証明。
- 代替運用中の承認・証跡・後日取込手順。
