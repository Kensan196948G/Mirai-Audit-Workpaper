# 用語集

本書は、本プロジェクト内で用いる語の意味をそろえるためのものです。社内規程や法令上の定義がある場合は、その定義が優先されます。

| 用語 | 本プロジェクトでの意味 |
|---|---|
| 年間監査計画 | 年度内の監査テーマ、対象、担当、時期等を定める計画 |
| 個別監査計画 | 一つの監査について目的、範囲、手続、担当、日程、必要証憑等を定める計画 |
| 監査案件 | 個別監査を案件単位で表した呼称（識別子: 監査案件番号）。手続・依頼・調書・指摘の親単位 |
| 監査役会 | 監査役が組織する合議体。監査計画・重要論点・監査結果を審議し、承認記録を残す |
| 監査事務局 | 監査役会・監査役の事務を補助する組織（総務部等）。日程・依頼・会議運営を支援する |
| 会計監査人 | 会社法に基づき会計監査を行う公認会計士・監査法人。計画・論点・発見事項の共有対象 |
| 内部監査部門 | 内部監査を実施する部門。監査役とは別の組織として連携・情報共有する |
| 補助使用人 | 監査役の職務を補助するため監査役会の同意で選任される使用人 |
| 監査手続 | 監査目的を達成するために実施する閲覧、照合、質問、観察、再計算等の確認行為 |
| 監査調書 | 実施手続、証拠、事実、評価、結論、レビューを記録した文書 |
| 証憑 | 取引、判断、統制、対応等を裏付ける文書・データ・記録 |
| 証跡 | 誰が、いつ、何を行ったか、どの根拠で結論に至ったかを追跡するための記録 |
| 正本 | 承認を経て正式版として保存される文書 |
| 草稿 | 作成・共同編集・レビュー中で、正式版ではない文書 |
| 版 | 文書の改訂状態。変更前後を識別するための番号・記号 |
| 母集団 | サンプリング対象となる全件の集合 |
| サンプリング | 母集団から一部を選び、監査手続を行うこと |
| 発見事項 | 監査手続により把握され、評価・報告の対象となる事実や問題 |
| 監査意見 | 得られた証拠と評価に基づき、権限を持つ監査人が示す判断 |
| 指摘 | 改善や対応を求める監査上の事項 |
| 是正計画 | 指摘に対し、責任者、対応内容、期限、完了条件を定めた計画 |
| フォローアップ | 指摘への対応状況や是正の有効性を再確認すること |
| 完了証憑 | 是正措置を実施したことを裏付ける資料 |
| 差戻し | 不足や不整合の理由を示し、修正・再提出を求めること |
| レビュー | 調書等の根拠、手続、結論、記載品質を別の権限者が確認すること |
| 承認 | 権限者が内容を確認し、次の状態または正式版とすること |
| 被監査部門 | 監査の対象となり、証憑・説明・是正対応等を行う部門 |
| 最小権限 | 業務に必要な人へ、必要な情報・操作だけを許可する考え方 |
| 職務分離 | 起案、実施、レビュー、承認、システム管理等を適切に分けること |
| 監査ログ | 閲覧、変更、承認、出力、権限変更等の操作履歴 |
| 追記専用 | 過去の記録を上書き・削除せず、新しい記録だけを追加する性質 |
| リーガルホールド | 訴訟・調査等に備え、対象情報の通常廃棄を停止して保全する措置 |
| 機密区分 | 情報の重要性・性質に応じて閲覧や取扱いを分ける分類 |
| SSO | 一度の認証で複数サービスを利用できる仕組み |
| MFA（多要素認証） | パスワード以外の要素も組み合わせて本人確認する仕組み |
| AppSuite | 本構想で計画・台帳・申請・承認・期限管理に利用候補とされる製品 |
| desknet's NEO | 本構想でポータル、通知、会議、依頼・督促に利用候補とされる製品 |
| OneDrive | 本構想で草稿の共同編集・作業用保存に利用候補とされる製品 |
| DirectCloud | 本構想で確定調書・受領証憑等の正本保管に利用候補とされる製品 |
| AI | 本構想では要約・検索等を補助し得るが、監査判断を代替しない技術 |
