# 様式・チェックリスト集

## 1. 年度監査計画

- 年度、目的、重点領域、リスク評価
- 監査対象、予定時期、担当、必要能力
- 会計監査人・内部監査部門との連携
- 予備日、報告予定、監査役会承認

## 2. 個別監査計画

- 監査ID、監査テーマ、背景、目的、範囲、対象期間
- 適用規程・評価基準、対象部門、担当者
- 監査手続、サンプル方針、必要証憑、ヒアリング先
- 日程、利益相反確認、レビュー担当、承認状態

## 3. 証憑依頼

- 依頼ID、監査ID、依頼内容、対象期間、形式
- 利用目的、機密区分、提出先、期限、依頼者
- 不明点の連絡先、提出可否・代替資料、受領・差戻し記録

## 4. 監査調書

- 調書ID、監査ID、表題、目的、作成者、作成日
- 手続、対象母集団、サンプル、実施内容、事実
- 根拠証憑ID、例外、評価、結論、未解決事項
- 作成者確認、レビューコメント、対応、承認者・承認日

## 5. 発見事項・指摘

- 指摘ID、件名、事実、評価基準、原因、影響
- 根拠調書・証憑、重要度案、被監査部門見解
- 改善要求、責任者、期限、承認、報告先

## 6. 改善計画

- 指摘ID、対策、期待効果、責任者、期限
- 中間マイルストーン、必要資源、残存リスク
- 完了条件、完了証憑、延期理由・承認

## 7. フォローアップ

- 指摘ID、確認日、確認者、確認手続
- 提出証憑、実施状況、有効性、残存事項
- 完了／継続監視／再指摘、判断理由、次回確認日

## 8. レビュー・承認チェック

- [ ] 目的と手続が対応している
- [ ] 事実と評価が分けて書かれている
- [ ] 結論が根拠証憑まで追跡できる
- [ ] 証憑の出所、対象期間、版が識別できる
- [ ] 例外と未解決事項が明示されている
- [ ] 利益相反と権限が確認されている
- [ ] レビューコメントへの回答が残っている
- [ ] 個人情報・機密情報の表示範囲が適切である
- [ ] 保存区分と保存期間が設定されている

## 9. 本番移行判定

- [ ] 業務責任者が要件・業務フローを承認した
- [ ] 役割別の受入試験が完了した
- [ ] 権限一覧と実アカウントが一致した
- [ ] バックアップからの復元試験に成功した
- [ ] 監査ログの検索・保全を確認した
- [ ] 利用者教育と問い合わせ窓口の準備が完了した
- [ ] 重大な未解決リスクがない、または責任者が受容した
- [ ] 移行・切戻し・緊急連絡手順が承認された

> 本書は項目案である。正式様式は監査役会規程、監査基準、文書管理規程に合わせて承認する。
