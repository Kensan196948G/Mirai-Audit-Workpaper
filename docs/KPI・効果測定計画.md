# KPI・効果測定計画

## 1. 目的

導入効果を「画面数」ではなく、監査品質、説明可能性、期限遵守、利用者負担、安全性で評価する。目標値は基準値を実測してから承認する。

## 2. KPI候補

| 分類 | 指標 | 算出例 | 注意点 |
|---|---|---|---|
| 品質 | 必須調書充足率 | 完了した必須調書数÷必要な必須調書数 | 形式的な作成を品質と誤認しない |
| 追跡性 | 証憑リンク完全率 | 根拠証憑へ到達できる結論数÷全結論数 | リンク先の権限と版も確認する |
| レビュー | 初回レビュー通過率 | 差戻しなし調書数÷レビュー済み調書数 | 高すぎる場合はレビュー形骸化も確認する |
| 期限 | 証憑期限内提出率 | 期限内提出数÷期限到来数 | 正当な期限変更を分離する |
| 改善 | 指摘期限内完了率 | 期限内に確認完了した指摘数÷期限到来数 | 自己申告ではなく証憑確認後を完了とする |
| 効率 | 依頼から受領までの日数 | 受領日時－依頼日時 | 監査種類・難易度別に比較する |
| 安全 | 不正アクセス・誤共有件数 | 確認された事象数 | ゼロ件でも検知不足がないか確認する |
| 利用 | 業務完遂率 | システム上で完了した対象監査数÷全対象監査数 | ログイン回数だけを成果にしない |
| 満足 | 役割別負担感 | 定期アンケート | 匿名性と少人数集計に配慮する |

## 3. 測定時点

導入前に基準値を測定し、試行監査終了時、本番3か月後、6か月後に再測定する。数値だけでなく、遅延理由、差戻し理由、現場の困り事も記録する。

## 4. 停止指標

誤権限付与、監査記録の消失・改ざん、重大な個人情報漏えい、復旧不能、監査独立性への重大な影響を確認した場合は、効果KPIにかかわらず対象機能を停止して是正する。

## 5. 未確定事項

対象監査の母数、現行所要時間、目標値、測定責任者、報告先、集計頻度、許容する例外条件。
