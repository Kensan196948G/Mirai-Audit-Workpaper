# よくある質問

## このシステムが監査の結論を出しますか？

いいえ。システムは計画、証憑、調書、レビュー、期限、履歴を整理します。監査判断、法的評価、処分、承認は権限を持つ人が行います。

## 被監査部門は監査調書を見られますか？

原則として、自部門への依頼、提出資料、事実確認、改善依頼など許可された範囲だけです。監査側の検討メモ、他部門の情報、未確定評価は分離します。正式な範囲は監査役会規程等で確定します。

## 提出した証憑を差し替えられますか？

訂正版の提出は可能ですが、以前の版を消して上書きする運用にはしません。差替え理由、提出者、日時、版、どの調書が参照したかを残します。

## メール添付で証憑を送ってよいですか？

原則は承認済みの提出場所を利用します。メールには機密資料そのものではなく、必要に応じてアクセス制御された依頼先への案内を記載します。

## 期限に間に合わない場合は？

期限前に理由、見込日、影響を連絡し、監査役が期限変更またはエスカレーションを判断します。変更前の期限と承認履歴を残します。

## 総務部はすべての内容を見られますか？

いいえ。日程・通知・会議支援に必要な情報と、監査の評価・機密証憑は分離できます。どこまで閲覧できるかは職務分掌に基づいて確定します。

## AIを使えますか？

承認された用途・情報区分・サービスに限ります。要約や検索補助に使う場合も、根拠資料を人が確認します。個人情報、通報者情報、未公表情報を未承認AIへ入力しません。

## 間違えて閲覧・共有した場合は？

自己判断で隠さず、直ちに指定の情報セキュリティ連絡先へ報告します。対象、相手、時刻、操作、拡散可能性を保全し、指示に従います。

## 「完了」は誰が決めますか？

証憑を提出しただけでは完了ではありません。監査役が改善内容と完了証憑を確認し、完了、継続監視、再指摘のいずれかを判断します。

## 現在すぐ利用できますか？

まだ利用できません。このワークスペースには構想・要件・設計文書があり、稼働アプリケーションは含まれていません。製品選定、規程確認、実装、試験、教育、本番承認が必要です。
