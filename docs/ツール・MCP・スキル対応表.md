# ツール・MCP・スキル目的別対応表

本プロジェクト（Mirai Audit Workpaper）で利用可能なツール群と、その適用判断を記録する。
対象は文書プロジェクト（実装コード・稼働環境なし）のため、適用対象は文書の精査・検証・管理に限定される。

## 1. MCP / 外部サービス

| ツール | 目的 | 認証・権限 | 読書き | 本プロジェクトでの適用 | 適用判断の根拠 |
|---|---|---|---|---|---|
| filesystem | ファイル・文書の読み書き、検証 | セッション許可ディレクトリ | 読書可 | ✅ 使用 | 文書群の精査・更新・リンク検証に必須 |
| bash | スクリプト実行（リンク検証・HTML構造検証） | セッションサンドボックス | 実行 | ✅ 使用 | check-links.py の実行と検証に使用 |
| web_search | 一般情報の参照 | — | 読 | ⚪ 状況による | 製品候補（AppSuite等）の仕様確認時のみ |
| GitHub MCP | リポジトリ・PR管理 | 要認証 | 読書 | 🔴 未使用 | 本ワークスペースはローカルGitのみ。リモート未設定のため |
| Cloudflare MCP | Workers/Pages/D1等の実装・デプロイ | 要アカウント | 読書 | 🔴 未使用 | 本プロジェクトに実装コード・デプロイ対象がないため |
| Neon MCP | Postgres DB管理 | 要アカウント | 読書 | 🔴 未使用 | 本プロジェクトにDB実装・マイグレーション対象がないため |

## 2. スキル

| スキル | 適用 | 判断 |
|---|---|---|
| autodesign-run ほか（ポスター・スライド・ランディング生成系） | 🔴 未使用 | 学術ポスター・論文スライド等の生成向け。監査業務・証跡管理の文書群には該当する成果物がないため対象外 |

## 3. 本プロジェクト固有の検証手段

| 手段 | 用途 | 実施方法 |
|---|---|---|
| scripts/check-links.py | 全 Markdown／HTML 相対リンクの検証 | `python3 scripts/check-links.py`（PASS を確認） |
| HTML構造検証 | タグ整合・閉じ忘れの確認 | セッション内で html.parser を使用 |
| レスポンシブ・印刷確認 | viewport・@media の有無 | 各HTMLのCSS確認 |

## 4. 記録・見直し

- 本表はツール環境の変化（GitHub連携開始、採用製品のPoC着手など）時に更新する。
- 適用判断は「外部書込み前に無害な読取りで接続先・権限・対象環境を特定する」原則に従う。
